# Stream encrypt/decrypt with passphrase= on the public API

## Business acceptance criteria

### Outcome

Backup (and other callers) can `from l3io.wp.database import encrypt, decrypt,
check_passphrase` and stream-encrypt any byte stream (including archives) with
`passphrase=`, with stock `age -d` recovery and DecryptionError vs CorruptDumpError.

Spec: none — epics.md Story 2.1 / plan-4 Part B; design-spec §7.3 encryption to be
amended in Story 2.4.

### Non-goals

Does not wire dump/load (Story 2.2). Does not add CLI flags (Story 2.3). Does not
amend ADR/spec (Story 2.4).

## Technical acceptance criteria

### Interface contracts

```python
def encrypt(reader, writer, recipients=None, *, passphrase=None) -> None
def decrypt(reader, writer, identities=None, *, passphrase=None) -> None
def check_passphrase(passphrase: str) -> None
```

Exactly one of recipients/passphrase (encrypt) or identities/passphrase (decrypt).
Re-export `encrypt`, `decrypt`, `check_recipients`, `check_passphrase`,
`generate_identity` from package root `__all__`. Passphrase path calls
`pyrage.passphrase.encrypt_io` / `decrypt_io`. Sibling convention: keep
implementation in `encryption.py`; root re-exports like `generate_identity`.

Spec: none — plan-4 Part B; will gain design-spec anchors in Story 2.4.

### Error and edge case handling

Both set / neither / empty passphrase → `InvalidArgumentsError` (no passphrase in
message). Wrong passphrase → `DecryptionError`. Truncated/non-age →
`CorruptDumpError`. Missing encryption extra → `MissingDependencyError`.

Spec: none — plan-4 Part B rules; FR10–FR11.

### Observability requirements

No passphrase in logs, spans, or exception messages (spec §2.4). Existing structlog
patterns unchanged.

Spec: none — design-spec §2.4 / §8; ADR-0003 amendment in Story 2.4.

### Security considerations

Lazy import behind `encryption` extra; base install forbids pyrage. Passphrase never
on argv (library receives `str` from caller). Scrypt sole recipient.

Spec: none — plan-4 NFR2–NFR3, NFR8.

### Testability approach

Extend `tests/test_encryption.py`: chunked-reader round-trip; stock `age -d` when
on PATH; wrong passphrase / truncate; mutex cases; API-surface `__all__` guard;
base-install forbidden import still includes pyrage.

Spec: none — plan-4 Part D test table.

### Existing-library check

`pyrage>=X,<2` from Story 1.2; no age CLI subprocess; no hand-rolled scrypt.

Spec: none — ADR-0003 / plan-4 rejected paths.
